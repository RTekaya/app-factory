# Security

App Factory runs coding agents that execute commands in your project. Its guardrails (deny rules, a frozen spec, the quality gate) reduce risk, but they are not a sandbox. Prefer a container or VM for long unattended runs.

To report a vulnerability (for example, a way for a role to bypass the guardrails or exfiltrate secrets), email **contact@zenith-ai.dev** rather than opening a public issue.
